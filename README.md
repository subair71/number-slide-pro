# Number Slide Pro

Flutter sliding puzzle game starter with 3×3, 4×4 and 5×5 boards, coins, daily challenges, rewarded AdMob ads and optional Firebase leaderboard.

## Getting started

1. Install Flutter SDK and Android SDK.
2. Run `flutter create --platforms android --project-name number_slide_pro .`.
3. Run `flutter pub get` and `flutter run`.
4. Configure Firebase (Anonymous Auth and Firestore) and Android AdMob application ID before release.
5. Build with `flutter build appbundle --release` after setting up Android signing.

**Release caution:** This is starter code, not a verified production build. Real AdMob IDs, consent, secure leaderboard validation, privacy disclosures, Play Console listing, device testing and release signing are still required.
